# Ember documentation

| Document | What it covers |

Also see the [README](../README.md) for an overview and [CONTRIBUTING.md](../CONTRIBUTING.md) for the code rules.

Ember is a preview. The C API is not frozen, and these documents describe the code as it is at this revision.
