| *.woff / *.woff2 | generated from the TTF/OTF above with fontTools 4.68 | WOFF/WOFF2 round trips |

`assets/fonts/ember-default.ttf` is a fontTools subset of NotoSans-Regular (Latin/Greek/Cyrillic + punctuation/symbols, unhinted, all layout features).

`sysfonts/` and `bitmap/` are generated by `tools/fonts/make_fixtures.py` (pure Python, no packages; deterministic): small TrueType fonts with one rectangle per glyph and advance 600, for the system font index tests (`sysfonts/`: a nested tree, a .ttc, a .woff, per-script faces named like the families the fallback tables prefer, a .fon and a .txt the index must skip) and the bitmap colour glyph tests (`bitmap/`: CBDT strikes of 16, 32 and 64 ppem in formats 17, 18 and 19, an sbix strike, and a face with both COLR and CBDT). They are original files, not derived from other fonts.
